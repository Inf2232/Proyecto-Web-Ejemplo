## Clonar el repositorio

```bash
git clone https://github.com/Inf2232/Proyecto-Web-Ejemplo.git
cd Proyecto-Web-Ejemplo



Ejecutar localmente

Abre el archivo index.html en tu navegador (doble clic o arrastra al navegador).

También puedes usar la extensión Live Server en VS Code para tener recarga automática.
Ramas del proyecto

    main – Versión estable y final del sitio. Contiene el código completo con todos los estilos y contenido.

    feature-mejora-estilo – Rama de desarrollo donde se aplicaron mejoras visuales: fuente moderna, fondo fijo, efectos hover, diseño responsive y optimización de elementos como el menú y el pie de página. Esta rama se fusionó con main resolviendo conflictos en estilos.css e index.html.
